## 统一执行请求模型

```rust
struct ExecutionRequest {
    run_id: RunId,
    node_id: NodeId,
    node_def: Arc<NodeDef>,
    inputs: ExecutionInputs,
    exec_signature: ExecSignature,
    generation: GenerationId,
    timeout_ms: Option<u64>,
    cancel_token: CancelToken,
    progress_sink: ProgressSink,
}
```

### 字段语义

- `run_id`：所属执行轮次
- `node_id`：当前正在执行的节点实例
- `node_def`：权威节点定义
- `inputs`：已解析完成的最终输入值
- `exec_signature`：缓存签名
- `generation`：缓存代际
- `timeout_ms`：节点级超时，默认来自 `NodeDef.execution`
- `cancel_token`：节点级取消令牌
- `progress_sink`：节点级进度上报通道

## 输入输出模型

```rust
type ExecutionInputs = HashMap<String, Value>;
type ExecutionOutputs = HashMap<String, Value>;
```

约束：

- 输入 key 对应节点正式输入口名称；
- 输出 key 对应节点正式输出口名称；
- 参数输出接口不要求执行器显式返回。

## 执行状态模型

```rust
enum ExecutionStatus {
    Idle,
    Running,
    Cancelling,
}

struct RunningExecution {
    execution_id: ExecutionId,
    target: ExecuteTarget,
    mode: ExecutionMode,
}

struct ExecutionState {
    status: ExecutionStatus,
    current: Option<RunningExecution>,
}

struct ExecutionResultSummary {
    execution_id: ExecutionId,
    status: ExecutionTerminalStatus,
    target: ExecuteTarget,
    mode: ExecutionMode,
    finished_nodes: Vec<NodeId>,
    failed_nodes: Vec<NodeId>,
}

enum ExecutionTerminalStatus {
    Finished,
    Cancelled,
    Error,
}
```

## 取消与进度模型

```rust
trait CancelToken: Send + Sync {
    fn is_cancelled(&self) -> bool;
}

trait ProgressSink: Send + Sync {
    fn report(&self, event: ExecutorProgressEvent);
}

enum ExecutorProgressEvent {
    Message { text: String },
    Fraction { current: u32, total: u32 },
    Preview { output: String, value: Value },
}
```

说明：

- 调度器负责 run 级取消；
- 执行器消费节点级 `CancelToken`；
- 进度模型是执行器与运行时之间的共享协议，不直接等于最终 `EngineEvent`。

## 执行器错误模型

```rust
enum ExecutorError {
    Unavailable { message: String },
    InvalidInput { message: String },
    Timeout,
    Cancelled,
    RuntimeFailed { message: String },
}
```

转换规则：

- `ExecutorError` 由运行时转为 `NodeError` 或 `ExecutionError`
- 不直接暴露到底层前端 contract
