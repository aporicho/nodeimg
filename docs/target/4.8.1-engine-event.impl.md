# 引擎事件模型

> `EngineEvent`（引擎事件，EngineEvent）的权威定义与 payload（负载，payload）规范。

---

## 文档状态

本文件是 **.impl**。

- 事件系统接口已确定为统一 `publish(event)`；
- 本文件定义统一事件枚举和各事件 payload；
- `4.8.0-events.impl.md` 关注事件系统机制，本文件关注事件模型本身。

---

## 定义

`EngineEvent` 是引擎对 GUI / CLI / AI 操作员广播的统一事件枚举。

一句话：

> **EngineEvent = 所有外发事件的唯一公共载体。**

---

## 提供接口

本文件不定义发布机制，只定义事件模型；发布机制见 `4.8.0-events.impl.md`。

## Payload 定义

```rust
struct ProjectChanged {
    reason: ProjectChangeReason,
    state: ProjectState,
}

enum ProjectChangeReason {
    New,
    Opened,
    Saved,
    SavedAs,
    Closed,
}

struct GraphChanged {
    reason: GraphChangeReason,
    graph_version: u64,
    dirty: bool,
}

enum GraphChangeReason {
    NodeAdded { node_id: NodeId },
    NodeRemoved { node_id: NodeId },
    Connected { from: PinRef, to: PinRef },
    Disconnected { from: PinRef, to: PinRef },
    ParamChanged { node_id: NodeId, param: String },
    BatchApplied,
    Undo,
    Redo,
    GraphReplaced,
}

struct PreviewChanged {
    node_id: NodeId,
    param: String,
}

struct NodeStarted {
    execution_id: ExecutionId,
    node_id: NodeId,
}

struct NodeProgress {
    execution_id: ExecutionId,
    node_id: NodeId,
    current: u32,
    total: u32,
    preview_handle: Option<Handle>,
}

struct NodeFinished {
    execution_id: ExecutionId,
    node_id: NodeId,
}

struct NodeError {
    execution_id: ExecutionId,
    node_id: NodeId,
    error: EngineError,
}

struct ExecutionFinished {
    result: ExecutionResultSummary,
}

struct ExecutionCancelled {
    result: ExecutionResultSummary,
}

struct ExecutionError {
    result: ExecutionResultSummary,
    error: EngineError,
}

struct ArtifactSelected {
    node_id: NodeId,
    artifact_id: ArtifactId,
}

struct ArtifactWriteFailed {
    node_id: NodeId,
    artifact_id: Option<ArtifactId>,
    error: EngineError,
}

struct BackendStatusChanged {
    kind: BackendKind,
    status: BackendStatus,
}
```

## 事件顺序与投递语义

1. 同一 producer（事件生产者，producer）发出的事件保持 FIFO（先进先出，FIFO）顺序
2. 不同 producer 之间不承诺全局总顺序
3. 同一节点执行内必须满足：
   - `NodeStarted -> NodeProgress* -> NodeFinished/NodeError`
4. 单次执行最终必须收到以下之一：
   - `ExecutionFinished`
   - `ExecutionCancelled`
   - `ExecutionError`

---

## 设计约束

- `GraphChanged` 不承载布局变化；
- 高频事件允许合并：`NodeProgress`、`PreviewChanged`；
- 关键终态事件不得丢弃；
- 跨模块边界统一暴露稳定 payload，不直接泄漏内部实现结构。
